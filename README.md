# سيرة — Sira Dashboard

لوحة تحليل تفاعلية لمشروع تخرج **«سيرة»**: منصة ذكاء اصطناعي بتحلل السيرة الذاتية وتساعد الخريج في التوظيف.

**🔴 Live Demo:** <https://ziad-alhusseiny.github.io/sira-dashboard/>

> نسخة عرض (Prototype) ببيانات تجريبية — في المنتج النهائي بتتوصل بالـ API بتاع موديلات الـ AI.

## المكوّنات

- **درجة التوافق (ATS Match Score)** — عدّاد دائري متحرك لنسبة توافق الـ CV مع الوظيفة
- **الترتيب المئوي** — «أقوى من ٧٣٪ من السير في مجالك» مع منحنى توزيع الدرجات
- **ملفك مقابل متطلبات الوظيفة** — مقارنة على ٥ محاور مع tooltips وعرض جدولي
- **ترشيح الوظائف** — أنسب ٥ وظائف مرتبة بنسبة التوافق (Semantic Similarity)
- **فاحص جودة الكتابة** — ملاحظات تحريرية بأمثلة تصحيح
- **خريطة التعلم** — المهارات الناقصة وكورس مجاني لكل واحدة
- **مولّد خطاب التقديم** — Cover Letter مخصص للوظيفة بتأثير كتابة حية وزرار نسخ

## التقنيات

HTML / CSS / Vanilla JS — بدون أي مكتبات خارجية. يدعم الوضع الفاتح والغامق، اتجاه RTL، أرقام عربية، وresponsive على الموبايل، مع مراعاة `prefers-reduced-motion` وألوان متوافقة مع عمى الألوان.

## التشغيل محليًا

افتح `index.html` في المتصفح مباشرة — مفيش build ولا dependencies.
